SYNTHSTATION v1

A focused web DAW: arrange clips on tracks in the sequencer, then edit each clip's notes in the piano roll.

Workflow

Tracks are horizontal lanes. Clips are movable blocks of notes on tracks. Instruments belong to clips (with track default instrument helpers). Left-click to draw, Shift + left-drag to select, Ctrl + left-drag to erase, then double-click a clip (or press Tab while a clip is selected) to edit notes in the Piano Roll.

Important notes

Recording from the Piano Roll uses a short count-in and starts from the current playhead within the clip; press the record button again (or Esc) to stop recording. Split mode (K) only works in Sequencer and exits after a successful split. Bars and clip length fields are auto-sized based on content, and loop/follow states are saved with the project.
